DLList(双向链表)

双向链表的“灵魂”在于它的节点。与（单向）链表不同，DLList 的每个节点不仅知道它的下一个 (next) 节点是谁，还知道它的上一个 (prev) 节点是谁。

这个 Node 类最好是作为 DLList 的一个内部私有类 (private inner class)，因为除了 DLList 自己，没有其他人需要知道 Node 的具体实现细节。

现在我们来构建 DLList 类本身。它需要两个实例变量：

  1. size：一个 int，用于跟踪链表中有多少个元素。

  2. sentinel：一个 Node，这是实现 DLList 最巧妙的地方。

什么是哨兵节点 (Sentinel Node)？

它是一个“虚拟”的、不存储任何真实数据的“哑 (dummy)”节点。我们用它来同时代表链表的“头部”和“尾部”。

  • sentinel.next 将永远指向第一个真实节点。

  • sentinel.prev 将永远指向最后一个真实节点。

使用哨兵有什么好处？

它能消除所有烦人的“空指针”边界情况！

  • 你再也不用写 if (head == null) 这样的代码了。

  • 一个空链表就是一个 sentinel 节点自己指向自己的状态。

  • 添加第一个元素或删除最后一个元素，与在链表中间操作的逻辑变得完全一致。

3. 关键操作：实现 add 和 remove

这是双向链表的核心。关键在于正确地更新所有相关的 prev 和 next 引用。

A. addFirst(T item)

目标： 在 sentinel 和“旧的第一个节点”之间插入一个新节点。

图解 (addFirst)：

  • 之前: Sentinel <--> OldFirst

  • 之后: Sentinel <--> NewNode <--> OldFirst

B. addLast(T item)

目标： 在“旧的最后一个节点”和 sentinel 之间插入一个新节点。

图解 (addLast)：

  • 之前: OldLast <--> Sentinel

  • 之后: OldLast <--> NewNode <--> Sentinel

C. removeFirst()

目标： 移除 sentinel.next 指向的节点，并返回它的 item。

图解 (removeFirst)：

  • 之前: Sentinel <--> NodeToRemove <--> NewFirst

  • 之后: Sentinel <--> NewFirst

D. removeLast()

目标： 移除 sentinel.prev 指向的节点，并返回它的 item。

图解 (removeLast)：

  • 之前: NewLast <--> NodeToRemove <--> Sentinel

  • 之后: NewLast <--> Sentinel

4. 辅助方法

最后，你需要一些辅助方法来让你的类更易用。

这就是实现一个带哨兵节点的泛型 DLList 的完整思路和关键代码。

Generics(泛型)

DLList<Double> s1 = new DLList<>(5.3);

这里的<>是指java中的核心特性–泛型(Generics)

  • 尖括号就像一个“标签”，你用它来告诉一个“容器”类（比如 DLList），这个容器专门用来装什么类型的东西。

  • 为什么需要泛型？

    DLList 就像一个盒子：

    • 没有尖括号：DLList s1 = new DLList();

      • 这是一个什么都能装的盒子。你可以往里面放一个 Double (5.3)，一个 String (“hello”)，甚至一个 Dog 对象。

      • 问题： 当你从盒子里取东西时，你只知道它是个 Object（对象），你不知道它具体是什么。你必须强制转换它 (Double d = (Double) s1.get(0);)。如果你猜错了（比如你以为是 Double，但取出来的是 “hello”），程序就会在运行时崩溃。

    • 有尖括号 (泛型方法)：DLList<Double> s1 = ...

      • 标志只能存放Double类型

      • 优点1 (类型安全 Type Safety)： 如果你试图往里放一个 String (s1.add("hello");)，程序在编译时就会立刻报错。这就提前帮你防止了 bug。

      • 优点 2 (免去强制转换 No Casting)： 当你从这个盒子里取东西时（s1.get(0)），Java 100% 确定它是一个 Double。你不需要再做任何强制转换，可以直接用 Double 变量来接收它：Double d = s1.get(0);

      在 Java 泛型中，你不能使用基本类型 (primitive types)（比如 int, double, char）。

      你必须使用它们对应的包装类 (Wrapper Classes)。

      • 错误：DLList<int> list = ...

      • 正确：DLList<Integer> list = ...

      • 错误：DLList<double> list = ...

      • 正确：DLList<Double> list = ...

      1. 如何 使用 泛型类 (最常见的用法)

      这是你已经见过的用法，比如使用 Java 自带的 ArrayList 或你自己的 DLList。

      核心： 在声明变量和创建对象时，用 <> 告诉 Java 你这个容器里要装什么。

      示例：使用 ArrayList

      2. 如何 定义 自己的泛型类

      当你创建 DLList 类时，需要使用一个占位符（通常是单个大写字母，比如 T）来代表“某个未来会指定的类型”。

      在 class 名字后面加上 <T>，然后在类内部用 T 作为类型。

      示例：创建一个泛型的 Box 类

      这个 Box<T> 类怎么用呢？

      在你的 DLList<T> 项目中，你的 Node 节点会有一个 T item 变量，你的 addFirst(T x) 方法会接受一个 T 类型的参数。

      3. 如何 定义 泛型方法 (工具方法)

      我们可以创建一个不依赖于泛型类的、独立的泛型方法。

      在方法的返回类型之前，加上 <T> 来声明它是一个泛型方法。

      示例：一个打印任何类型数组的工具方法

Array(数组)

每当创建一个数组时，你会得到一个引用，如果丢掉了对这个数组的唯一引用，那么他将永远无法取回（类和对象同理），也就是会被垃圾回收(Garbage Collection, GC)

和类不同的是，我们不能对数组添加自定义的方法，它们只是数据 ，会有长度(lenght)和一系列编号的内存框

System.arraycopy(b, 0, x, 3, 2);：

  • 从b数组的[0]索引开始的两个值复制到x数组的[3]索引开始的两个值身上

  • 如果x位置不够会崩溃

  • 这种方法比手动for循环复制数组要快
