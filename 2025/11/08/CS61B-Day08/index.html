Interface Inheritance(接口继承)

它告诉子类应该能够做什么。

所有的列表都应该能够打印自己，具体如何实现由它们自己决定。

Implementation Inheritance(实现继承)

一个子类（Subclass）从一个父类（Superclass）继承。

它会同时继承父类的代码实现和数据（字段）。

特性 接口继承 (Interface Inheritance) 实现继承 (Implementation Inheritance)
目的 规范行为 (What you can do) 共享实现 (What you are)
关系 “Can-do” 关系 (e.g., can-fly) “Is-a” 关系 (e.g., Dog is an Animal)
继承内容 抽象方法签名、常量 具体的方法实现、字段（状态）
多重继承 支持（一个类可以 implements 多个接口） 不支持（一个类只能 extends 一个父类）
耦合度 低（解耦） 高（紧耦合）
主要好处 灵活性、可扩展性、可替换性 代码复用

特性 重载 (Overloading) 重写 (Overriding)
发生位置 同一个类中 父类与子类之间
方法名 必须相同 必须相同
参数列表 必须不同 必须相同
返回类型 可以不同（但不能仅靠返回类型区分） 必须相同（或是父类返回类型的子类）
目的 用一个名字做多种（参数不同的）类似的事 子类改变或特化父类的行为
多态性 编译时多态（静态绑定） 运行时多态（动态绑定）

Interface(接口)/class(类)

interface只规定了你能做什么，而不是如何去做

class则负责了具体的实现细节(如何去做)

特性 Class (类) Interface (接口)
目的 蓝图 (Blueprint)：用来创建对象 契约 (Contract)：用来定义行为规范
实例化 可以被实例化（new MyClass()） 不可以被实例化（new MyInterface()）
包含内容 • 状态 (字段 / 成员变量)
• 实现 (有方法体的具体方法)
• 构造函数		 传统上只包含：
• 行为签名 (无方法体的抽象方法)
• 常量 (e.g., final static)
继承 单继承 (一个类只能 extends 一个父类) 多继承 (一个接口可以 extends 多个接口)
实现 一个类可以 implements 多个接口 N/A (接口是被类实现的)
关系 “Is-a” (是一个)
(e.g., Dog is an Animal)		 “Can-do” (能做到)
(e.g., Dog can Run)
