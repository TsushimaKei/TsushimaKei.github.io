SLList VS AList

数据结构 操作 (Operation) 时间复杂度 (Time Complexity) 备注
SLLiSt (单链表) 头部插入 $O(1)$ 非常快（常数时间）
尾部 / 按索引插入¹ $O(N)$ 需要遍历（线性时间）
AList (数组列表) 尾部插入 $O(1)$ (摊销) 平均很快（摊销常数时间）
头部 / 按索引插入 $O(N)$ 需要移动元素（线性时间）#

Inheritance(继承)/Overloads(重载)

Interface Inheritance(接口继承)

    接口继承指的是一个子类继承超类的所有方法/行为的关系。

Implementation Inheritance(实现继承)

    理解实现继承的时候应该理解成是一个（is - a) 而不是有一个(has - a)

  • IS-A (是一个) => 继承 (Inheritance)

    • 子类 是 父类的一种更具体的类型。

    • 示例：

      • 在 public class Dog implements Animal 的例子中，Dog 是一个 (IS-A) Animal。

      • 正因为如此，你可以写 Animal a = new Dog();，因为 Dog 满足 Animal 接口所定义的所有规范（它“是”一个 Animal）。

      • 一个 ArrayList 是一个 (IS-A) List。

特性 实现继承 (extends) 接口继承 (implements)
关键字 extends implements
继承内容 代码实现 和 数据字段 方法规范 (API 签名)
关系 “IS-A” (是一个) “Can-Do” (能做)
目的 代码复用、特化 定义规范、多态
多重继承 不允许 (只能继承一个类) 允许 (可以实现多个接口)
