java是一个静态类型的语言，不具备有损的隐式转换的功能，定义为int类型时无法赋予5.3这样的值（c语言中则是可以赋值但是会导致精度丢失，也就是“隐式转换”）

特性 C 语言 Java 语言
int i = 3.14; 允许（编译通过） 不允许（编译错误）
转换方式 隐式转换（Implicit） 必须显式转换（Explicit Cast）
结果 自动截断小数，i 变为 3 必须写成 int i = (int)3.14;，i 才会变为 3
设计哲学 灵活，相信程序员 严格，强调类型安全，防止意外的数据丢失
